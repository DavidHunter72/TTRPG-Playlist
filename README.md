TTRPG Spotify Playlist Generator.
________________________________________
This project is an AI-powered web application that generates immersive playlists for tabletop role-playing games (TTRPGs). The goal was to enhance storytelling by providing dynamic, theme-based music that matches different in-game scenarios such as combat, exploration, or mystery. The application is built using Streamlit for the user interface, allowing for a simple and interactive experience.
Users begin by entering a scene description, such as “boss battle in a volcano” or “mysterious forest exploration.” This input is sent to the OpenAI API, which generates a curated list of six songs formatted for easy processing. These song suggestions are then matched using the Spotify API, enabling the app to display real tracks with album artwork and direct links.
A key feature of the application is its dynamic user interface. The background uses animated gradients that adapt to the user’s input theme, creating a more immersive and visually engaging experience. This enhances the connection between the generated music and the narrative context.
One challenge encountered during development was integrating Spotify’s playlist creation features in a cloud environment. Due to authentication limitations, full playlist export is currently supported only in the local version of the app. However, the deployed version still allows users to explore and access songs directly.
Overall, this project demonstrates how AI and API integration can be combined to create interactive tools that enhance creativity and user engagement in gaming environments.
